# exo__AssetSpace_lastPulledSha

StringProperty recording SHA of last successful pull для AssetSpace cache invalidation + drift detection при switch operations.

## Semantics

- **rdfs:domain:** `[[73bd00e4-ccc0-4f3f-b20d-c4388c4588fb|exo__AssetSpace]]`
- **rdfs:range:** `xsd:string` (40-char hex commit SHA — implicit via StringProperty metaclass)
- **Cardinality:** 0..1 (`[[5ca2ae4b-d254-4462-a8a1-82bcd5bad951|exo__PropertyCardinalityOptional]]`)
- **Owner:** plugin writes via vault adapter post-pull

## RFC reference

Per [[0a0791c1-3808-42fd-bc7f-bdd127ac7b24|RFC 0a0791c1 — FocusProfile Phase 4 plugin runtime]] Phase A.1. Complements existing `[[add55499-f6b7-4867-ace8-323d97d10143|exo__AssetSpace_git]]` (repo URL) — together they enable cache invalidation logic: if `lastPulledSha` ≠ current remote HEAD → cache stale, refresh required.
