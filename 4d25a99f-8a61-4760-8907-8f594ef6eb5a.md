# exo__FocusProfile_extends

Указание parent profile, который inherited. Per RFC b6ba5595.

## Semantics

- **Domain:** `exo__FocusProfile`
- **Range:** `exo__FocusProfile`
- **Cardinality:** 0..1 (single optional parent)
- **Display name:** `extends`

Effective `_includes` = `own._includes ∪ resolve(parent)`. Single-parent inheritance избегает need for MRO / C3 linearization.

## Facets / Invariants

- **Max depth:** `extends*` chain bounded к 5. Enforced в Phase 3 hook `validate-focusprofile-cycle.sh`.
- **Cycle-free:** CQ4 SELECT-COUNT `cycleCount = 0` required для valid vault state.
- **Self-extension prohibited:** `profile.extends = profile` (degenerate cycle), checked отдельно в hook.
