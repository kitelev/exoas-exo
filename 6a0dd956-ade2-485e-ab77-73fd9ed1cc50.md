# `exo__Asset_legacyValidationException`

Property для grandfathering существующих нарушений валидации в Phase 4 sweep (Shared SHACL-lite Validation Engine).

- **Назначение** — пометить ассет, что его текущее состояние нарушает какую-то constraint, но это историческое нарушение и движок должен его пропустить
- **Value** — строка с reason/explanation, объясняющая почему violation grandfathered
- **Cardinality** — 0..1 (один ассет = одно exception value)
- **Engine semantics** — при наличии этой property валидатор должен пропустить (skip) обнаруженное violation для данного ассета и логировать его как grandfathered

## Применение

- Bulk-applied в Phase 4.3 на ассеты из Phase 4.2 triage
- Idempotent: no-op если exception уже выставлен
