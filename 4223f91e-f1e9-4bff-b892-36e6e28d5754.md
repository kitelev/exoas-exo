Parser-derived datatype property: file basename (без `.md` расширения, URL-decoded) каждого `exo__Asset`. **Read-only** — values эмитятся parser'ом при reindex, не asserted в frontmatter.

- **Range:** `xsd:string`. Materialized через class `[[30d63ce4-e574-456c-8de8-2bf1a53688c1|exo__StringProperty]]`.
- **Domain:** `[[493c2ae2-de56-47ec-954d-2eb8cb49bff7|exo__Asset]]` — applicable to all assets.
- **Cardinality:** 1 (каждый файл имеет ровно один basename). Derived — при parser malfunction graph state may show 0; double-emit запрещён через overwrite-on-reindex semantics (см. ниже).
- **Super-property:** `[[0be06648-acee-4c8d-bfb7-53fc14155ea2|exo__Asset_derivedAttribute]]` — провенанс marker.
- **Idempotency (per RFC M3):** перед эмитом нового `exo:Asset_filename` triple для subject S, indexer удаляет prior triple `<S> exo:Asset_filename ?any`. Set-semantics RDF store недостаточна — если filename изменился между reindex'ами, без overwrite было бы 2 triples с разными values. Phase 3 acceptance: double-reindex → graph identity (no duplicates).
- **Provenance contract:** parser-emitted, не user-asserted. Не использовать в frontmatter — будет затёрто на следующем reindex.
