# exo__KnowledgeProfile_extends

Parent Knowledge Profile к inherit от. Per RFC 52f2acdd.

## Semantics

- **Domain:** `exo__KnowledgeProfile`
- **Range:** `exo__KnowledgeProfile`
- **Cardinality:** 0..1 (single optional parent)
- **Display name:** `extends`

Effective materialization set = `own._includes ∪ resolve(parent.effectiveSet) ∪ own._alwaysOnOverlay`. Single-parent inheritance избегает MRO/C3 linearization complexity.

## Facets / Invariants

- **Cycle-free:** CQ SELECT-COUNT `cycleCount = 0` required для valid vault state
- **Self-extension prohibited:** `profile.extends = profile` (degenerate cycle), checked separately
