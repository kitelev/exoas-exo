# exo__KnowledgeProfile

User-declared subset of ontologies for filesystem materialization. Counterpart к `exo__FocusProfile` (runtime filter). Per RFC 13da049f Phase 6 (consumer) + RFC b6ba5595 v2 (declarative homoiconic) + RFC 52f2acdd (this class' declaration).

## Semantics

KnowledgeProfile прескриптивно описывает «какие онтологии user хочет materialize on disk» — counterpart к FocusProfile («какие онтологии user хочет filter at query time»).

| Aspect | exo__KnowledgeProfile | exo__FocusProfile |
|---|---|---|
| Action | Filesystem materialization | RDF query filter |
| Trigger | Hard switch palette command | Soft switch palette command |
| Lifecycle | Slow (weeks/months) | Fast (hours/days) |
| Active state | `activeKnowledgeProfileUid` | `activeFocusProfileUid` |
| Industry analog | npm install, apt install, branch checkout | grep filter, music playlist, search query |

⚠️ KnowledgeProfile + FocusProfile **NOT disjoint** — same instance MAY be dual-class (legacy migration default, see Phase 6 v1.3 §Backward compat).
