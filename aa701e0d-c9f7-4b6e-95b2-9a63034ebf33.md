# exo__Dependency

Reification class for version-constrained AssetSpace dependencies (per RFC-AS-001 `d11f95b2-6017-4f40-81e5-d427c622906c` + companion onto-RFC `8f20f1f3-8a51-41c7-8385-c1275df05894`).

Each instance carries exactly one `exo__Dependency_imports` (target AssetSpace) plus exactly one `exo__Dependency_versionRange` (semver constraint string, node-semver grammar).

Disjoint with `exo__Ontology` and `exo__AssetSpace` (siblings under `exo__Asset`).
