# exo__FrontmatterOrderSpec

Класс, описывающий канонический порядок полей при создании frontmatter. Default instance (с `_default: true`) применяется ко всем creation paths (Concept, Area, Class, Generic, Supervision, Grounding, CLI Asset).

## Properties

- `exo__FrontmatterOrderSpec_head` — список property local-names, идущих первыми
- `exo__FrontmatterOrderSpec_tail` — список property local-names, идущих последними
- `exo__FrontmatterOrderSpec_middleStrategy` — стратегия сортировки middle блока (`alphabetical` в v1)
- `exo__FrontmatterOrderSpec_default` — boolean, отмечает global fallback spec

## Расширяемость

Пользователь может добавить/удалить/переставить entries в `_head` / `_tail` через vault edit. Next creation pick up без plugin release. См. RFC `27a7a877-691f-46b0-bc0a-4c746b4ccb17` в vault-exodev/inbox/.
