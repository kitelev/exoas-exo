# exo__Setting_value

Типизированное значение настройки. Per onto-RFC 981b6070 (D23).

## Semantics

- **Domain:** [[88b938af-1a55-451c-b3cc-2f03e5115fcf|exo__Setting]]
- **Range:** variant по datatype ключа — `xsd:boolean` / `xsd:string` / список строк (YAML list). Конкретный тип объявлен `exo__SettingKey_datatype` целевого `exo__Setting_key` → детерминированная code-coercion + типизированное SPARQL-сравнение (CQ4 «настройки ≠ default»).
- **Cardinality:** 1..1 (REQUIRED)
- **Display name:** `value`

Metaclass — generic `exo__DatatypeProperty` (не StringProperty): конкретный literal-тип определяется per-key, а не фиксирован на property-уровне.
