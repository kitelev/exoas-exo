# exo__Asset_archived

Boolean archive flag of an asset (`true` = archived). Declared 2026-09-15 by founder decision (ticket `da0f73a3-dffa-4dfc-9579-090131d05724`, S7).

## Semantics

- Frontmatter key: `exo__Asset_archived: true` (canonical). Legacy carriers use the bare Obsidian-style key `archived: true`; both are indexed as `exo:Asset_archived "true"`, so SPARQL preconditions (`Not archived`, `Is archivable`, `Archived and not yet ontologically archived`, …) see both forms.
- Writers (`archive` command grounding, `ArchiveAssetService`, CLI `archive`, batch archive) emit only the canonical key and drop the bare one; `un-archive` removes both.
- Migration of legacy carriers: `exocortex-cli repair-frontmatter <path> --canonicalize-keys`.
- Requirement: `960d7a3f-c04c-461e-a7fa-1ba2d2572bee` (exoas-exo-reqs). Deprecated alias: `exo__Asset_isArchived` (`7f632d25`, read-only compatibility in code, never written).
