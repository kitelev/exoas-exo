# exo__Property_severity

Severity level for SHACL-lite shape constraints — controls how the validation engine reacts when an instance violates a property's domain/range/cardinality invariant.

## Range (W3C SHACL aligned)

- `sh:Violation` — block write (default if absent)
- `sh:Warning` — log + UI notice, write proceeds
- `sh:Info` — audit log only

W3C namespace: `http://www.w3.org/ns/shacl#`. RDF range = `sh:Severity`. The three IRIs are not yet materialised as vault assets — referenced by IRI/CURIE in shape registry until [[eb78fd9e-82a6-4931-8b29-5cb5c534da0a]] / `sh__Severity` ontology stub lands (out of scope of P0.2).

## Cardinality

`0..1` (encoded as `exo__PropertyCardinalitySingle`). Engine semantics: missing value defaults to `sh:Violation`.

## superProperty

Intended `sh:severity` (W3C SHACL). Wikilink `[[eb78fd9e-82a6-4931-8b29-5cb5c534da0a]]` deliberately omitted from frontmatter — `sh__severity.md` does not yet exist in vault and forward-pointing wikilink is blocked by `validate-wikilinks` hook (UWI rule). Add the alignment edge once SHACL namespace is bootstrapped.
