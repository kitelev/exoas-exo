# exo__PrintedPropertyValueSource

Закрытый перечень источников значения для `exo__PrintedProperty`, когда значение свойства — ссылка на ассет.

| индивид | что печатается |
|---|---|
| `exo__PrintedPropertyValueSourceLabel` | `exo__Asset_label` цели — сегодняшнее поведение; равно ОТСУТСТВИЮ объявления |
| `exo__PrintedPropertyValueSourceDisplayName` | СОСТАВЛЕННОЕ имя цели (её собственный `exo__DisplayNameSpec`), даже если label есть |

`DisplayName` — **предпочтение, а не гарантия**: если составить имя нечем (нет спека, цикл, исчерпана глубина),
печатается label, затем — сам linkpath. Границы разворота — те же, что ввёл req `0f992e88`.

req `ff1482f2`, issue #4303.
