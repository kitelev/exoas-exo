# exo__DisplayNamePart (abstract)

Абстрактный суперкласс частей displayName-спецификации. Несёт общие свойства `_of` (родительский spec) + `_order` (позиция). Конкретные подклассы:
- `exo__PrintedProperty` — часть, печатающая значение свойства (single-hop).
- `exo__PrintedLiteral` — часть, печатающая статический литерал.

⚠ **Abstract convention-only (panel-minor #2):** SHACL-lite не имеет `sh:abstract` → голый `exo__DisplayNamePart`-инстанс формально пройдёт shapes. Движок рендерит пусто для `Instance_class = exo__DisplayNamePart` (engine-side convention). Не создавать инстансы напрямую — только подклассы.
