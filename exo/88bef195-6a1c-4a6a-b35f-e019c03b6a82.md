Layer `Adapter` of the ontology layering, rank `15`.

Member of the sealed `exo__OntologyLayer` enumeration; see the class asset for the full table and the
conformance rule (an edge must run from a higher `_order` to a lower or equal one).

An adapter (bridge) ontology connects two domain ontologies through `exo__Statement` assertions and
definition edges, so it depends on both (rank 10); application ontologies (rank 20) may depend on it.
Rank 15 sits in the gap left between Domain and Application, so no existing member is renumbered.
Members: the `$adapter-*` ontologies and the bridges introduced by RFC `14217015` (`$idea-ems`,
`$idea-flow`, `$exoization-decorables`, `$desk-mappings`).

The layer is assigned by meaning, not derived from the import graph; `ontology-layer-derive.py`
only checks the direction of imports and definition edges (RFC `14217015` §1, decision No. 7).

RFC `14217015-963b-4020-b267-fd13b1275b3a` (§1, leaf P1.1).
