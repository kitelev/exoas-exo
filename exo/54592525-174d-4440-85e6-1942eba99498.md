The ontology namespace(s) an AssetSpace supplies to the graph. Cardinality 0..N — an AssetSpace may
provide several namespaces (e.g. `exoas-public` provides `ems`, `concept`, `person`, `period`, …),
and an AssetSpace that provides none is legitimate (content-only spaces).

Range: `exo__Ontology`. This is the declarative inverse view of `exo__Asset_isDefinedBy`: instead of
each asset naming its ontology, the AssetSpace descriptor names which ontologies live inside it, so
the registry can answer "which AssetSpace do I mount to obtain namespace X" without scanning assets.

Supersedes the single-valued `exo__AssetSpace_namespace` (deprecated) for the multi-namespace case;
the deprecated property is not touched here.
