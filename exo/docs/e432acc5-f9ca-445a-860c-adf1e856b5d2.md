**Prototype** (`exo__Prototype`) — ассет-шаблон, чьи значения свойств **наследуются инстансами** через prototype chain (аналог JS-прототипа, наследование ЗНАЧЕНИЙ, не class-subsumption).

## Механика
- `exo__Asset_prototype` на инстансе → указывает на прототип.
- Значения прототипа жадно материализуются в named graph `exo:inferred`; ExoQL `OWN()` отличает собственные значения инстанса от унаследованных.
- Транзитивная цепочка (`resolveChain`) с cycle-guard + depth-cap (`MAX_PROTOTYPE_DEPTH`) — тотальность dataization (рекурсия всегда bounded).

## Genotype/phenotype (φ/EO)
Git = генотип (явно-установленные свойства); runtime RDF store = фенотип (+ вычисляемые унаследованные).

## Отличие от класса
`exo__Class` + `superClass` = **типовая** иерархия (что это); прототип = наследование **значений** конкретного экземпляра (какое по умолчанию). Инстанс может иметь и класс, и прототип одновременно.
