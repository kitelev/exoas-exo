Kind of an `exo__AssetSpace_dependsOn` edge into this AssetSpace: **hard** (the target supplies TBox
definitions or commands — without it instances lose their type, so it can never be parked) or **soft**
(the target supplies content only — without it links become unresolved, types stay intact).

Read from the graph by the plugin (`closureGap` / `unmountSafety`) to decide whether an unmounted
closure member is TBox-critical. Absent value is treated as **hard** (safe default).
