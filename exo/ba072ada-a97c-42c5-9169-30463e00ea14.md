# exo__Profile_description

One-line, human-readable description of what the profile mounts and who it is
for. Surfaced in the «Exocortex: Apply profile» picker so a tester can tell the
profiles apart without decoding the `$$`-prefixed names (RFC 0002 §3.4, P7).

## Semantics

- **Domain:** `exo__Profile`
- **Range:** literal string (`exo__DatatypeProperty`)
- **Cardinality:** 0..1 (optional — a profile without it just shows the label)
- **Display name:** `description`

Per the Homoiconicity invariant the picker reads this RDF property directly —
descriptions are vault data, never hardcoded in the plugin. Any profile asset
can carry one without a code change.
