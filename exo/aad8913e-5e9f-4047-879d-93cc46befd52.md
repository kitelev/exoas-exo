# exo__FileSpace

Пространство opaque-блобов (вложения/файлы), которое RDF-индексатор **пропускает**: контент не парсится, не попадает в triple store, не проходит SHACL. Per onto-RFC 18808c73 (companion к RFC ExoSync 4e4dc453).

## Taxonomy

- `exo__FileSpace ⊑ exo__Space ⊑ exo__Asset` — superclass [[8f3e976a-2d6b-4fa4-9336-53aa01320e18|exo__Space]].
- **Sibling:** [[73bd00e4-ccc0-4f3f-b20d-c4388c4588fb|exo__AssetSpace]] — оба «git-backed материализуемое пространство», различаются обработкой контента (parse vs skip) — один уровень общности (§4.2 OK).
- **Disjoint with:** `exo__AssetSpace` — пространство не может быть одновременно asset- и file-типа (declarative; SHACL-lite не enforce'ит — residual risk R5).

## Semantics

- Индексатор решает «парсить vs пропускать» по `rdf:type` пространства: AssetSpace → парсить, FileSpace → skip. Тип объявлен в RDF; код лишь читает декларацию (Homoiconicity Q3 — исключение 1, ядро обработки).
- Наследует shared git-backed словарь от exo__Space (domain-widened, Pull-up Option A): [[d89ad355-38b3-4ba8-adba-cd3c03312009|exo__AssetSpace_source]], [[fdec4916-ab21-4969-b9a4-c43db36e4903|exo__AssetSpace_namespace]], [[add55499-f6b7-4867-ace8-323d97d10143|exo__AssetSpace_git]], [[39aa5429-ce54-4350-95c2-e38794a89669|exo__AssetSpace_version]].
- Ссылки на файлы — path-based (`![[image.png]]`), без UID.
- Включается в профиль через [[24d1ce5e-b5a2-4c78-9498-eb46ee24e22e|exo__Profile_includes]] (range = exo__Space, subclass-closure).
- Пример инстанса: репозиторий `08 Files/`-вложений (exofs-kitelev-files).
