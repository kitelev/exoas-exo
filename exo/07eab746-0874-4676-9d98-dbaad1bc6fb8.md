# exo__DisplayNameSpec

Класс, описывающий как собирается displayName для инстансов заданного класса (v1 thin: single-hop parts + literals, priority-selection).

## Свойства (v1)
- `exo__DisplayNameSpec_appliesToClass` — класс, который лейблит (range exo__Class, 1)
- `exo__DisplayNameSpec_priority` — приоритет отбора (xsd:decimal, 0..1; default 0)

Части spec связаны через `exo__DisplayNamePart_of` (UWI child→parent). Selection: spec, чей `_appliesToClass` = класс ассета (exact или engine hierarchy-walk — НЕ SPARQL `Class_superClass*`, сломан dual-IRI) → max `_priority` (tie: specificity→UID). Fallback: нет spec → `exo__Asset_label` → basename → UID.

⚠ **Instance-label caveat (panel-minor #3):** инстансы `exo__DisplayNameSpec` должны иметь human/UID label, НЕ `prefix__LocalName` — иначе `_of`-join уходит в symbolic IRI и `_of` резолвится пусто.

v2 (отдельный проект): рекурсия, многохоп `_path`, условная `_matchPath`/`_matchValue`, format-facet.
