# exo__Profile_recommended

Marks a profile as recommended for new users. When `true`, the «Exocortex:
Apply profile» picker decorates the profile with a «Recommended for new users»
badge — typically the `starter` profile a fresh tester applies (RFC 0002 §3.4,
P7).

## Semantics

- **Domain:** `exo__Profile`
- **Range:** boolean (`exo__BooleanProperty`)
- **Cardinality:** 0..1 (absent ⇒ `false`)
- **Display name:** `recommended`

RDF-driven (Homoiconicity invariant): the badge follows this property, not a
hardcoded label match, so any profile may be marked recommended.
