# exo__Profile_imports

Parent profile, который этот профиль композирует (Maven parent-POM аналогия). Per RFC 01a83de8 Phase 2 (rename from exo__FocusProfile_extends).

## Semantics

- **Domain:** `exo__Profile`
- **Range:** `exo__Profile`
- **Cardinality:** 0..1 (single optional parent — MVP)
- **Display name:** `imports`

Effective `_includes` = `own._includes ∪ resolve(parent)._includes`. Single-parent MVP избегает need for MRO / C3 linearization. **Transitive 0..N + cycle-guard + diamond dedup → Phase 4** (для текущих 4 профилей multiple-composition = YAGNI).

⛔ **UUID-form mandate:** значение `_imports` — только UUID-wikilink (`[[<profile-uid>]]`). Label-form резолвится в literal → literal-safety guard молча обнуляет CQ-замыкание.

## Facets / Invariants (re-enabled when 0..N в Phase 4)

- **Max depth:** `_imports*` chain bounded к 5. Enforced в hook `validate-focusprofile-cycle.sh`.
- **Cycle-free:** CQ-COUNT `cycleCount = 0` required для valid vault state.
- **Self-import prohibited:** `profile._imports = profile` (degenerate cycle), checked отдельно в hook.
