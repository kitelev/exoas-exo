Multi-valued DAG link from an AssetSpace directly to the AssetSpace(s) it depends on. Cardinality 0..N. Range: `exo__AssetSpace`.

Range re-pointed from the now-removed `exo__Dependency` reification class to `exo__AssetSpace` per RR-A (RFC `de77fe27` §Review Resolution, 2026-06-13) — the unused Maven-style dependency reification (`exo__Dependency` + `_versionRange` + `_imports`) was removed (0 code consumption, RFC-AS-001 superseded). This property is retained as the real AssetSpace-DAG edge for future use.
