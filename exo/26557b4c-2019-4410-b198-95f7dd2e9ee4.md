Multi-valued link from an AssetSpace directly to the AssetSpace(s) it depends on — **УПАКОВКА** (что монтировать), ⛔ **не DAG** (см. рамку 2026-09-12 ниже: требование ацикличности объявлений снято). Cardinality 0..N. Range: `exo__AssetSpace`.

Range re-pointed from the now-removed `exo__Dependency` reification class to `exo__AssetSpace` per RR-A (RFC `de77fe27` §Review Resolution, 2026-06-13) — the unused Maven-style dependency reification (`exo__Dependency` + `_versionRange` + `_imports`) was removed (0 code consumption, RFC-AS-001 superseded). ⛔ Прежняя редакция этого абзаца называла свойство «the real AssetSpace-DAG edge» — снято рамкой 2026-09-12.

## ⛤ РАМКА 2026-09-12 (решение фаундера, RFC `306dcb5c`, развилка `807eb832`; ярус покрытия — развилка `164de449`)

**Два инварианта на ДВУХ графах — не путать.**

1. **`exo__AssetSpace_dependsOn` — УПАКОВКА.** Объявляется автором; **циклы допустимы**. Требование «объявленный граф — DAG» **СНЯТО**. Основание — механизм, а не соглашение: все три потребителя цикло-устойчивы (`RegistryDependencyResolver` seen+queue · `transitiveDependsOnClosure` BFS с closure-set · `walkProfileChain` visited).
2. **ПОКРЫТИЕ — одностороннее и на ярусе ОПРЕДЕЛЕНИЙ:** каждый фактический defs-факт (`Ontology_imports`, `Property_range`, `Property_domain`, `Class_superClass`, `Property_superProperty`, `Property_cardinality`, `Property_minCount`, `Ontology_admits`) обязан быть **покрыт ПО ЗАМЫКАНИЮ** объявлений. ⛔ Не по прямому ребру: так читает движок и так устроена проверка Н2 («не покрыто» ⟺ цели нет в merged vault); прямое требование сделало бы инвариант строже собственного гейта. ⛔ Обратное («объявлено ⟹ есть факт») требованием **не является** — упаковочные объявления законны.
3. **АЦИКЛИЧНОСТЬ — свойство ФАКТОВ яруса defs**, не объявлений. Гейт — детектор циклов по фактам, ⛔ не Tarjan по объявлениям.
4. **Упаковку от протухшего объявления отличает `exo__AssetSpace_dependsOnKind`** (`DependencyKindReference` = упаковка).

⚠ **Следствие, которое видно в данных:** после закрытия покрытия (2026-09-12, `exoas-registry@d1d1d2c`, +26 объявлений) объявленный граф **содержит циклы** — например `exoas-exo ⇄ exoas-w3c-aggregated`. Это **ожидаемое** состояние, а не дефект: любой инструмент, читающий этот предикат, обязан быть цикло-устойчивым.
