# exo__AssetSpace_materialized

Runtime-derived boolean property indicating whether the AssetSpace is currently materialized on the local filesystem (`true`) or only declared via TBox (`false`).

**Not persisted** to `exo__AssetSpace` ABox frontmatter — computed at SPARQL/UI query time by `AssetSpaceMaterializationTracker` walking the `assetspaces/` directory.

Per RFC 22b50a17 Vision Lock #12 (refined 2026-06-02): runtime-derived only. No stale state risk if user manually `rm`/`cp` `assetspaces/` directories. Cheap walk (~13 folders typical for vault-2025).

## Usage

SPARQL queries may filter AssetSpace assets by materialization status:

```sparql
SELECT ?as WHERE {
  ?as exo:Instance_class exo:AssetSpace .
  ?as exo:AssetSpace_materialized true .
}
```

UI renders status icons (✅ materialized | ⏸ available) based on tracker state.
