# FrontmatterOrderSpec default

Global default spec — применяется для всех creation paths когда отсутствует class-specific spec. Параметры:

- **Head** (8 entries): isDefinedBy → uid → createdAt → Instance_class → prototype → Effort_status → Effort_area → Effort_parent
- **Middle:** alphabetical sort всех остальных полей
- **Tail** (3 entries): Asset_relates → Asset_label → aliases

User может extend через editing этого ассета — например добавить `ems__Effort_responsible` в `_tail` после `Asset_relates`. Изменение picks up следующим creation call без plugin release. Cм. RFC `27a7a877-691f-46b0-bc0a-4c746b4ccb17` в vault-exodev/inbox/.
