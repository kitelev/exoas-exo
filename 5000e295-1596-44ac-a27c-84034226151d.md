# exo__Property_minCount

Minimum number of values required for a property on an instance.

- Maps to W3C SHACL `sh:minCount`
- Used by SHACL-lite engine (Phase 3+) for mandatory field enforcement
- Integer ≥0; absent = no minimum constraint (default: unconstrained)
- Engine semantics: if instance has fewer than `minCount` values for this property, a violation of severity `exo__Property_severity` (default `sh:Violation`) is raised
