# setting__Setting

Cross-source base class for one user-configurable setting as a first-class vault asset (granular key+value model). Per RFC `f402002b` (M1.1), Homoiconicity Invariant (`c78cc5c8`).

## Model

- `setting__Setting ⊑ exo__Asset` ([[493c2ae2-de56-47ec-954d-2eb8cb49bff7|exo__Asset]]).
- **Predicates (inherited by all subclasses):** `setting__Setting_key` — ObjectProperty, range `setting__SettingKey`, 1..1; `setting__Setting_value` — generic DatatypeProperty (no fixed range — type per-key), 1..1.
- **Subclasses (per source):** `exo__Setting` (Exocortex plugin), `obsidian__Setting` (Obsidian core), `obsplugin__Setting` (other plugins). Subclasses **inherit** the predicates, do not re-declare.
- A generic Export/Import engine (M2) discovers settings across the whole `setting__Setting` subclass closure, distributing every source uniformly.
