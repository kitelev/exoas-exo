# setting__SettingKey

Cross-source base enum-class of canonical setting keys (per RFC `f402002b`, M1.1). Models the catalog of valid setting keys as graph data (Homoiconicity Invariant), not a code-side facet.

## Model

- `setting__SettingKey ⊑ exo__Asset` ([[493c2ae2-de56-47ec-954d-2eb8cb49bff7|exo__Asset]]).
- **Instances = enum-individuals** — one per distributable setting key (or validation-check id, M1.3). Each carries `setting__SettingKey_datatype` (`boolean` | `string` | `stringList`) → deterministic value-coercion + typed SPARQL-join.
- **Predicate:** `setting__SettingKey_datatype` — StringProperty (enum literal), 1..1.
- **Subclasses (per source):** `exo__SettingKey` (Exocortex), `obsidian__SettingKey` (Obsidian core), `obsplugin__SettingKey` (other plugins). Inherit the predicate.
- Used as the range of `setting__Setting_key`.
