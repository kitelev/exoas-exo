# setting__SettingKeyExocortexDistributionOntology

Meta-setting key (string value) for the **distribution-ontology** target of the homoiconic settings-distribution framework (RFC `f402002b`, M2.2 — §5).

- `exo__Instance_class: setting__SettingKey` (cross-source key catalog).
- `setting__SettingKey_datatype: string` — a `setting__Setting` carrying this key holds the **opaque AssetSpace UID** the Exocortex domain distributes its settings into (not a raw repo-URL — the floor public anchor is world-readable, RFC sec F8).
- **Homoiconic, not a master switch:** this records *where* settings distribute (a target). It is DISTINCT from the non-homoiconic master switch `settingsHomoiconizationEnabled` (which is on/off).
- **Reader:** the core `resolveDistributionOntology(assets, keyUid)` resolves the recorded AssetSpace UID from the floor `setting__Setting` instance carrying this key, returning `null` when no meta-setting is recorded (default-on-absence = location-convention → the caller picks the target). The key UID is exported from core as `EXOCORTEX_DISTRIBUTION_ONTOLOGY_KEY_UID`.
