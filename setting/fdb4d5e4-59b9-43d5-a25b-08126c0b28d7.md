# setting__SettingKey_datatype

Declared value-type of a setting key. Inherited by all `setting__SettingKey` subclasses (RFC `f402002b`, M1.1).

## Semantics

- **Domain:** [[26684801-b352-4d90-82f5-e13b7648b546|setting__SettingKey]]
- **Range:** string-literal enum — the allowed values are exactly `boolean` | `string` | `stringList` (lowercase tokens, literals not individuals). Code-coercion reads the literal directly.
- **Cardinality:** 1..1 (REQUIRED — each key must declare its type, else coercion is non-deterministic)
- **Display name:** `datatype`

The schema of valid settings + their types lives in the graph: `?key a setting:SettingKey ; setting:SettingKey_datatype ?dt`.
