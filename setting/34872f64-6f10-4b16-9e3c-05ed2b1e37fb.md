# $setting

Floor-anchored ontology for the **homoiconic settings-distribution framework** (RFC `f402002b`, M1). Declares the cross-source settings superclasses `setting__Setting` / `setting__SettingKey` (and their per-source subclasses `exo__` / `obsidian__` / `obsplugin__`), so that *what settings to distribute* and *which validation checks are enabled* live in the graph (Homoiconicity Invariant, `c78cc5c8`).

## Why floor-anchored

`exo__Setting` (and `exo__SettingKey`) re-parent under `setting__Setting` / `setting__SettingKey` (M1.2, additive). `exo__Setting` is part of the `$exo` TS-floor, so its superclass must be reachable whenever `$exo` is mounted. This ontology is therefore co-resident in the always-mounted `exoas-exo` AssetSpace (subfolder `setting/`) — floor-mount without a separate registered AssetSpace.

## Naming

`setting__` prefix ⇒ `setting` namespace (naming=namespace, D9) ⇒ this `$setting` ontology (`exo__Ontology_url: https://exocortex.my/ontology/setting#`), self-referential `isDefinedBy`.
