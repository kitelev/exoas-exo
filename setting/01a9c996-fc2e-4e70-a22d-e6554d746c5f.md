# obsplugin__Setting

Per-source subclass of [[35cf35fb-935f-4d35-a150-939f29109aec|setting__Setting]] for a **community-plugin** setting as a first-class vault asset. Per RFC `f402002b` (M4), Homoiconicity Invariant (`c78cc5c8`).

## Model

- `obsplugin__Setting ⊑ setting__Setting ⊑ exo__Asset`.
- **Inherits** the predicates from `setting__Setting` (does NOT re-declare): `setting__Setting_key` (range `setting__SettingKey`/subclass, 1..1), `setting__Setting_value` (generic, type per-key, 1..1).
- The generic Export/Import engine (M2 `SettingsDistributionEngine`) discovers these via the `setting__Setting` subClass-closure; M4 export snapshots a plugin's live `data.json` into `obsplugin__Setting` assets.
- **Pilot:** Periodic Notes — `obsplugin__SettingKey` individuals for the Daily Notes folder/format/template/enabled keys.
