# setting__ValidationCheckShacl

Validation-check key (boolean toggle) for the **SHACL-lite vault-wide** check. Per RFC `f402002b` (M1.3).

- `exo__Instance_class: setting__SettingKey` (cross-source key catalog; **not** `exo__SettingKey` — these check keys are distinct from the plugin's live-mirror settings and are read directly by `Validate vault`, not via `VaultSettingsRegistry`).
- `setting__SettingKey_datatype: boolean` — a check-Setting carrying this key has a boolean value (check enabled/disabled).
- **check-id ↔ runner:** this key's UID is the stable check-id the validate-command's runner registry maps to the SHACL-lite runner (warm `getTripleStore()`). An enabled check-Setting whose key has no registered runner is reported **fail-loud** (not silently skipped).
