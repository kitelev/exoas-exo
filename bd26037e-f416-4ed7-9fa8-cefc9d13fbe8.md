# exo__FocusProfile_appliesTo

Knowledge Profile к which этот Focus Profile applies. Compat constraint anchor для AC16 runtime validation. Per RFC 52f2acdd + RFC 13da049f Phase 6 v1.3.

## Semantics

- **Domain:** `exo__FocusProfile`
- **Range:** `exo__KnowledgeProfile`
- **Cardinality:** 0..1 (optional — empty means «applies to any active Knowledge, soft fallback runtime check only»)
- **Display name:** `appliesTo`

## Compatibility semantic (per consumer RFC 13da049f AC16)

When soft switch к этому FocusProfile triggered, plugin runtime validates:

1. **If `_appliesTo` declared** AND `activeKnowledgeProfileUid != _appliesTo.uid` → **WARN+fallback** (per AC16): console.warn, Notice к user, RDF filter set к no-filter mode
2. **If `_appliesTo` declared** AND `activeKnowledgeProfileUid == _appliesTo.uid` → proceed runtime `_includes ⊆ effective set` check
3. **If `_appliesTo` empty/null** → skip applies-to check, fall through к runtime `_includes ⊆` check only

Static TBox-level reference (this property) + runtime check (plugin code) combine для defense-in-depth. SHACL-lite cannot validate этот compat at vault write time (cross-asset state validation), so runtime is authoritative.
