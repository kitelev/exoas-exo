# exo__KnowledgeProfile_includes

Список онтологий, которые user хочет materialized на disk при этом Knowledge Profile. Per RFC 52f2acdd.

## Semantics

- **Domain:** `exo__KnowledgeProfile`
- **Range:** `exo__Ontology`
- **Cardinality:** 0..N (empty profile valid — useful для cold-start mode где effective_set = только overlay)
- **Display name:** `includes`

Effective materialization set вычисляется как `includes ∪ transitive(KnowledgeProfile_extends*) ∪ inherited(alwaysOnOverlay)`. Phase 6 ships **no transitive `Ontology_imports`** (M15 ABSENT) — user must add each required Ontology manually.
