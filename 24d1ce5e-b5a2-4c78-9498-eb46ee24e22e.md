# exo__FocusProfile_includes

Список онтологий, которые user хочет видеть активными при этом профиле. Per RFC b6ba5595.

## Semantics

- **Domain:** `exo__FocusProfile`
- **Range:** `exo__Ontology`
- **Cardinality:** 0..N (empty profile валиден — useful для minimum-load mobile mode где effective_set = только overlay)
- **Display name:** `includes`

Effective set вычисляется как `includes ∪ transitive(Ontology_imports*)` per CQ1.
