# exo__Property_pattern

Regex pattern constraint applied to literal values of a property. SHACL-lite engine validates that string values match the supplied ECMAScript regex.

- Maps to W3C SHACL `sh:pattern`
- Used by SHACL-lite engine (Phase 4+) для format / convention enforcement
- Value type: `xsd:string` — ECMAScript-compatible regex (anchors `^`/`$` recommended for exact-match)
- Absent = no pattern constraint (default: unconstrained)
- Engine semantics: если literal value не соответствует regex, raises violation severity `exo__Property_severity` (default `sh:Violation`)

## W3C Alignment

- `sh:pattern` → `xsd:string` (regex)
- Reference: [W3C SHACL §4.5.4 sh:pattern](https://www.w3.org/TR/shacl/#PatternConstraintComponent)

## Motivation

Enables RDF-declarative enforcement of naming conventions / URL formats / identifier patterns без TypeScript code changes. Originally needed for RFC `75b50f51-512e-473c-a253-77a7ad96eaa5` (AssetSpace Naming Convention `exoas-<namespace>`) — bijection между `_git` URL и `_namespace` property требует pattern check на `_git` literal.
