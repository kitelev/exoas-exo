# exo__FocusProfile_alwaysOnOverlay

Set of ontologies, считающихся always-on overlay для этого profile. Per RFC b6ba5595 v2 (post-review homoiconic compliance fix).

## Semantics

- **Domain:** `exo__FocusProfile`
- **Range:** `exo__Ontology`
- **Cardinality:** 0..N (empty allowed — relies on TS-default fallback cold-start)
- **Display name:** `alwaysOnOverlay`

Overlay add'ится дополнительно к effective_set (не входит в `_includes`). Per Ontology Engineer #6 review: материализация overlay в RDF восстанавливает homoiconic Q1=Yes compliance.

## Resolution semantics

1. Plugin вычисляет union all `_alwaysOnOverlay` across `<profile> _extends*` ancestors.
2. Если union пуст AND ни один FocusProfile в vault не declares `_alwaysOnOverlay` → plugin использует TS-hardcoded default: `$exo` + `$exocmd` + pattern-match `$shared-*` / `assetspaces/shared-identities/`.
3. Если хоть один profile declares overlay → overlay set = union per-profile inheritance. TS-default НЕ используется.

**Homoiconic property:** user может полностью override overlay (создать profile с explicit `_alwaysOnOverlay`); TS-default — лишь cold-start safety.
