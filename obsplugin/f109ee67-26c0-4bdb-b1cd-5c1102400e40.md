# obsplugin__SettingKey

Enum-class of canonical other-plugin setting keys. Per RFC `f402002b`.

- `obsplugin__SettingKey ⊑ setting__SettingKey` ([[26684801-b352-4d90-82f5-e13b7648b546|setting__SettingKey]] ⊑ `exo__Asset`).
- Inherits `setting__SettingKey_datatype`.
- Instances = enum-individuals, one per distributable plugin key (with accessor-path, M4).

## Model

- `obsplugin__SettingKey ⊑ setting__SettingKey ⊑ exo__Asset`.
- **Instances = enum-individuals** — one per distributable plugin setting key; each carries `setting__SettingKey_datatype` (`boolean` | `string` | `stringList`).
- **Inherits** `setting__SettingKey_datatype` (does NOT re-declare).
- Used as the range value of `setting__Setting_key` for `obsplugin__Setting` instances.
- **Pilot:** Periodic Notes Daily Notes — `folder`/`format`/`template` (string) + `enabled` (boolean).
