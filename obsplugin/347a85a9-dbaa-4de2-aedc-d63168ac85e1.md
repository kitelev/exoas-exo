# obsplugin__Setting

Other-plugin setting (e.g. Periodic Notes) as a first-class vault asset. Per RFC `f402002b`.

- `obsplugin__Setting ⊑ setting__Setting` ([[35cf35fb-935f-4d35-a150-939f29109aec|setting__Setting]] ⊑ `exo__Asset`).
- Inherits `setting__Setting_key` / `setting__Setting_value`.
- Instances created by Export `<plugin>` Settings (M4) — e.g. `vault.adapter.read('.obsidian/plugins/periodic-notes/data.json')`, mobile-safe.
